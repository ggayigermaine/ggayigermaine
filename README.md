## Principles

- **Never trust unverified identifiers across boundaries.** Resolve identity from an authoritative source.
- **UI implying a rule is not the rule being enforced.** The backend enforces it.
- **One resolution point per shared resource.** No component guesses its own shape.
- **Evidence over assertion.** Read the code; don't rely on a summary of it.
- **Premature abstraction is a cost.** Generalize only when a second real call site needs it.
- **Fix the pattern, not just the bug.**
